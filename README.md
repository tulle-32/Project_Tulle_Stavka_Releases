# Ставка — скачать

### [⬇ Скачать для Windows 10 / 11](https://github.com/tulle-32/Project_Tulle_Stavka_Releases/releases/latest/download/StavkaApp-win-Setup.exe)

Ссылка всегда ведёт на последнюю версию. Нужна другая сборка — таблица ниже. Остальное — в [справке](https://tulle-32.github.io/Project_Tulle_Stavka_Releases/help/index.html).

«Ставка» — программа для Windows: ставки банков по вкладам и накопительным счетам одним списком, ваш личный портфель и налог на проценты. Всё работает на вашем компьютере: ваши вклады и суммы никуда не отправляются.

## Windows говорит «Windows защитила ваш компьютер»

Это не вирус: так Windows встречает любую программу без дорогой цифровой подписи. Нажмите **«Подробнее»** (мелкая надпись под текстом) → **«Выполнить в любом случае»** — установка начнётся. Это один раз, при установке.

## Другие файлы

| Файл | Для кого |
|---|---|
| `StavkaApp-win-Setup.exe` | **Рекомендуется.** Для вас одного, права администратора не нужны, программа обновляется сама |
| `StavkaApp-win.msi` | Для всех пользователей компьютера (в `Program Files`), нужны права администратора |
| `StavkaApp-win-Portable.zip` | Без установки: распаковать и запустить |

Файлы `*.nupkg`, `RELEASES`, `*.json` служебные — их скачивать не нужно. Linux и macOS пока не поддерживаются.
