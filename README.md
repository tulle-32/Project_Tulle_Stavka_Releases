# Ставка

**Программа для Windows, которая отвечает на вопрос «куда положить деньги, чтобы получить больше».**
Следит за ставками банков по вкладам и накопительным счетам, сравнивает их в рублях на вашу сумму, ведёт ваш личный портфель и считает налог.
Всё работает на вашем компьютере: ваши вклады и данные никуда не отправляются.

## Что умеет

- **Ставки всех банков в одном месте.** Вклады и накопительные счета с сайтов банков, агрегаторов и ЦБ РФ; обновляются сами по расписанию. Повышенные ставки помечены («новым клиентам», «за траты по карте», «новым деньгам»).
- **Сравнение в рублях.** Введите сумму, и таблица сама покажет, сколько вы получите за срок, с налогом и без. Избранное, сравнение продуктов, оповещения, когда ставка выросла.
- **Ваш портфель.** Добавьте свои вклады и счета: доход по дням, что будет после окончания, предупреждение о лимите страховки АСВ.
  - **Выплаты процентов:** программа напоминает, когда должна прийти выплата, и вы подтверждаете «пришло столько же» одним щелчком. Доход и налог считаются по факту.
  - **Куда переложить:** по каждому продукту видно, где можно получать больше, с понятным планом переноса.
  - **Анализ:** где лежат деньги, когда что заканчивается, застраховано ли всё, сколько налога, что будет, если ставки упадут, как идёте к цели.
  - **Здоровье портфеля:** один балл из ста и список, что сделать, чтобы его улучшить.
- **Налог на проценты (НДФЛ).** Лимит без налога от ключевой ставки, налог по датам выплат, срок уплаты, отчёт за год.
- **История ставок.** Как менялись ставки по дням: таблица, коридор, календарь.
- **Удобство.** Тёмная и светлая тема, быстрый поиск и команды (Ctrl+K), горячие клавиши, экспорт в Excel и PDF, календарь окончаний, резервные копии.
- **Обновляется сама.** Новые версии скачиваются в фоне; останется нажать «Перезапустить сейчас».

## Какой файл скачать

Windows 10 и 11. Откройте последний выпуск в разделе Releases (справа на главной странице репозитория) и скачайте один из файлов:

| Файл | Для кого |
|---|---|
| `StavkaApp-win-Setup.exe` | **Рекомендуется.** Установка для одного пользователя, права администратора не нужны, программа обновляется сама |
| `StavkaApp-win.msi` | Установка для всех пользователей в `Program Files`, нужны права администратора (подойдёт для организаций) |
| `StavkaApp-win-Portable.zip` | Без установки: распаковать и запустить |

Остальные файлы (`*.nupkg`, `RELEASES`, `*.json`) служебные, их скачивать не нужно: из них программа берёт обновления.
Linux и macOS пока не поддерживаются.

## Первый запуск

1. Запустите установщик. Windows может предупредить: «Windows защитила ваш компьютер». Файлы пока не подписаны цифровой подписью. Нажмите **«Подробнее» → «Выполнить в любом случае»**.
2. Программа откроется и начнёт собирать ставки. Первый сбор занимает несколько минут: ставки появятся в таблицах по мере готовности.
3. Добавьте свой вклад кнопкой **«Добавить»** в разделе «Мои продукты». Можно ввести одной строкой или выбрать продукт прямо из таблицы ставок.

## Где лежат данные

- Программа: `%LocalAppData%\StavkaApp` (у MSI: `C:\Program Files`).
- Ваши данные (портфель, настройки, копии): `%LocalAppData%\StavkaData`. Они лежат отдельно: обновление и переустановка их не затрагивают, удаление программы тоже.
- Наружу программа обращается только к сайтам банков за ставками и к GitHub за обновлениями. Ваши вклады и суммы никуда не уходят.

## Если что-то пошло не так

Шестерёнка → **«Справка» → «Отчёт для разработчика…»**: программа соберёт отчёт о своей работе и подготовит письмо разработчику. Перед отправкой отчёт можно посмотреть.

## Удаление

«Параметры Windows» → «Приложения» → «Ставка». Папка с данными `%LocalAppData%\StavkaData` остаётся: при повторной установке всё вернётся.
