# Ставка — скачать

«Ставка» следит за ставками по вкладам и накопительным счетам банков, сравнивает предложения и считает ваш доход. Работает на вашем компьютере, личные данные никуда не отправляются.

**Что умеет**

- Собирает актуальные ставки с сайтов банков и показывает их одним списком: вклады и накопительные счета, срок, сумма, пополнение, капитализация.
- Показывает условия честно: повышенные ставки «новым клиентам», «за траты по карте», «новым деньгам» — отдельными строками с пометкой, а не вместо обычной ставки.
- Ведёт ваши вклады и считает доход, в том числе после налога.
- Следит за изменением ставок и показывает историю.
- Обновляется сама.

## Какой файл скачать

Откройте последний выпуск (раздел **Releases** справа) и в списке **Assets** выберите файл.

| Система | Файл | Для кого |
|---|---|---|
| **Windows 10 / 11** | `StavkaApp-win-Setup.exe` | **Рекомендуется всем.** Устанавливается для вас одного, права администратора не нужны, программа сама обновляется |
| Windows 10 / 11 | `StavkaApp-win.msi` | Установка «для всех пользователей» в `Program Files`. Нужны права администратора, на каждое обновление Windows спросит разрешение |
| Windows 10 / 11 | `StavkaApp-win-Portable.zip` | Без установки: распаковать в любую папку и запустить |
| Linux | — | пока нет |
| macOS | — | пока нет |

Остальные файлы выпуска (`*.nupkg`, `RELEASES`, `*.json`) служебные: их читает сама программа при обновлении. Скачивать их не нужно.

## Первый запуск

1. Запустите `StavkaApp-win-Setup.exe`. Windows может показать «Windows защитила ваш компьютер» — файлы пока не подписаны. Нажмите **«Подробнее» → «Выполнить в любом случае»**.
2. Программа откроется и начнёт собирать ставки (несколько минут при первом запуске — это нормально, список наполняется по мере работы).
3. Дальше она обновляется сама: при новой версии появится полоса «Перезапустить сейчас».

Ваши данные лежат в папке `%LocalAppData%\Stavka` и при обновлении и переустановке сохраняются. Если хотите перенести программу на другой компьютер, скопируйте эту папку.

## Если что-то не работает

В программе: значок шестерёнки → **Справка → «Отчёт для разработчика…»**. Нажмите **«Создать отчёт»** — программа соберёт один файл (без ваших вкладов, сумм и целей; из текстов убраны имя пользователя Windows и имя компьютера). Дальше можно нажать **«Написать письмом»** — письмо разработчику откроется в вашей почтовой программе с готовой темой, файл останется приложить. В отчёте есть необязательное поле «Как к вам обращаться» — впишите имя, чтобы разработчик знал, кому отвечать.

## Как удалить

Параметры Windows → Приложения → «Ставка» → Удалить. Папка с вашими данными (`%LocalAppData%\Stavka`) при удалении остаётся: если она больше не нужна, удалите её вручную.
