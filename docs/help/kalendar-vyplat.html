Как перенести даты в календарь телефона

Чтобы не пропустить окончание вклада и выплату процентов, пусть напоминание придёт из привычного календаря.

Что получите

Файл календаря (.ics) с датами окончания ваших вкладов и ближайших выплат. Он открывается в календаре телефона, Outlook и Google Календаре.

Шаги

  1. Откройте ⚙ и нажмите «Даты в календарь (.ics)…» (или Ctrl+K → «Экспорт в календарь (.ics)»). Сохраните файл и откройте его в календаре.
  2. Чтобы файл обновлялся сам, включите «Держать файл календаря свежим». Программа будет переписывать файл calendar\stavka.ics в папке данных при каждом изменении ваших продуктов. Подключите этот файл в календаре один раз. Пункт выключен по умолчанию.

Подписку по ссылке в интернете программа не создаёт: файл лежит только у вас на компьютере. В Outlook: «Добавить календарь → Из файла».
