Как установить «Ставку» и запустить в первый раз

Нужна Windows 10 или 11. Установка занимает минуту.

Что получите

Программа на вашем компьютере, которая сама собирает ставки банков и обновляется.

Шаги

  1. На странице «Скачать» нажмите «Скачать для Windows». Файл StavkaApp-win-Setup.exe — для одного пользователя, права администратора не нужны.
  2. Запустите файл. Если Windows показала синее окно «Windows защитила ваш компьютер» — нажмите «Подробнее» → «Выполнить в любом случае». Это не вирус: так Windows встречает программу без дорогой цифровой подписи. Бывает один раз, при установке.
  3. Программа откроется и начнёт собирать ставки. Первый сбор занимает несколько минут — ставки появляются в таблицах по мере готовности.
  4. Добавьте свой вклад — как это сделать.
  5. Дальше программа обновляется сама: при новой версии появится полоса «Перезапустить сейчас».
