Первый запуск: окно «Windows защитила ваш компьютер»

Установщик пока не подписан платным сертификатом, поэтому Windows при первом запуске осторожничает. Это не вирус — так Windows встречает любую новую программу без подписи.

  1. В синем окне нажмите мелкую надпись «Подробнее» — появится кнопка.
  2. Нажмите «Выполнить в любом случае» — установка начнётся.
  3. Нет кнопки? Щёлкните по файлу правой кнопкой → «Свойства» → внизу галочка «Разблокировать» → «ОК» и запустите снова.

Показывается один раз при установке; сама программа и её обновления предупреждений не вызывают. Данные хранятся в %LocalAppData%\StavkaData и при обновлении сохраняются.

Если что-то не работает: в программе — значок шестерёнки → Справка → «Отчёт для разработчика…». Удалить: Параметры Windows → Приложения → «Ставка».
